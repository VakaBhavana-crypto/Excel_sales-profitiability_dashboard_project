# Excel_sales-profitiability_dashboard_project
Developed an interactive Sales Analysis and Profitability Dashboard using Microsoft Excel to analyze revenue, gross profit, profit margins, and sales trends. Used PivotTables, charts, formulas, and interactive filters to visualize performance across products, regions, customer types, and sales channels, enabling data-driven business insights.
